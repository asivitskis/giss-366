# ArcGIS Online

[ArcGIS Online](https://www.arcgis.com/) is Esri's cloud-based GIS platform. It lets you publish geographic data, build hosted feature layers, design interactive web maps, and create no-code and SDK-based applications — all through your web browser, with no desktop installation required.

## Access

**No installation needed.** You will access ArcGIS Online at [WNMU's ArcGIS Online Homepage](https://wnmugis.maps.arcgis.com/home/index.html) using your **WNMU-provided ArcGIS Online account**.

> Do not sign up for a personal/free ArcGIS Online account for this course, use your WNMU organizational account so your work is properly licensed and stored within our institution's organization.

If you haven't received your account credentials, contact your instructor before the first lab that requires ArcGIS Online.

> **Note:** You do **not** need to install ArcGIS Pro (the desktop application) for this course unless specifically instructed otherwise. ArcGIS Online and ArcGIS Pro are different products. This course uses the online platform only.

## What We'll Use It For

- **Publishing data:** Upload shapefiles, CSVs, or GeoJSON and publish them as **hosted feature layers**
- **Web maps:** Combine layers, basemaps, and pop-ups into an interactive web map (Map Viewer)
- **No-code app building:** Turn a web map into a shareable application using **Experience Builder** or classic app templates — no programming required
- **SDK-based development:** Use the **ArcGIS Maps SDK for JavaScript** to build custom, code-based mapping applications (paralleling what we do with Leaflet and MapLibre GL JS, but within Esri's proprietary ecosystem)
- **Sharing and permissions:** Control who can view or edit your published content — an important entry point into our discussions of access, audience, and digital geoethics

## Key Areas of the Platform

| Area | Purpose |
| :---- | :---- |
| **Content** | Your uploaded data, feature layers, web maps, and apps |
| **Map Viewer** | Build and style interactive web maps |
| **Scene Viewer** | Build 3D web scenes |
| **Groups** | Share content with classmates or the whole class group |
| **Organization settings** | View sharing/permission levels for your account |

## Getting Started

1. Sign in at [arcgis.com](https://www.arcgis.com/) with your WNMU credentials.
2. Go to **Content → New Item** to upload a shapefile, CSV, or GeoJSON file.
3. Choose **Publish** to turn the uploaded file into a hosted feature layer.
4. Open the layer in **Map Viewer** to style it and add it to a web map.

Specific step-by-step instructions for each lab (e.g., Lab 2: Hosted feature layer + POI webmap) will be provided when that unit begins.
