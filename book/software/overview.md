# Software & Tools Overview

This course uses a combination of desktop software, web-based GIS platforms, and open-source web mapping libraries. You will **not** need to install every technology we use. Some tools are installed on your computer, while others are accessed through a web browser or used directly within your web mapping projects.

The goal of this page is to help you understand **what you need to install before the course begins** and what you will encounter later in the semester.

## What You Need to Install

### [Visual Studio Code](https://code.visualstudio.com/)

**Required**

Visual Studio Code (VS Code) is the primary code editor we will use to create and edit web mapping projects. You will use it to work with HTML, CSS, JavaScript, GeoJSON, and other web GIS files.

You will also install the **Live Server** extension, which allows you to preview web mapping applications locally in your browser.

[Learn more about Visual Studio Code →](vscode)

---

### [QGIS](https://qgis.org/)

**Required**

QGIS is a free and open-source desktop GIS. Although this is a Web GIS course, QGIS will be useful for preparing, inspecting, editing, and exporting geographic data that we use in our web maps.

Install the **Long Term Release (LTR)** version unless otherwise instructed.

[Learn more about QGIS →](qgis)

---

### [Git](https://git-scm.com/)

**Required**

Git is a version control system that we will use to track changes to web mapping projects and work with repositories hosted on GitHub.

You will install Git on your computer and learn the basic Git workflow needed for this course.

[Learn more about Git & GitHub →](github)

---

## Web-Based Platforms

These tools do **not** require a separate desktop installation.

### [ArcGIS Online](https://www.arcgis.com/)

**Required account**

ArcGIS Online is a cloud-based GIS platform that we will use to publish geographic data, create hosted feature layers and web maps, and explore no-code and SDK-based application development.

You will access ArcGIS Online through your web browser using your WNMU account.

> **You do not need to install ArcGIS Pro for this course unless specifically instructed otherwise.**

[Learn more about ArcGIS Online →](arcgis-online)

---

### [GitHub](https://github.com/)

**Required account**

GitHub is a platform for hosting Git repositories and publishing web projects. We will use GitHub alongside Git as part of our web development and deployment workflow.

You will need a GitHub account and will connect it to the Git software installed on your computer.

[Learn more about Git & GitHub →](github)

---

## Web Mapping Libraries

Leaflet and MapLibre GL JS are **JavaScript libraries**, not desktop applications. You do not download and install them like QGIS or VS Code.

Instead, we will include these libraries in our web mapping projects and use them from within our HTML and JavaScript code.

### [Leaflet](https://leafletjs.com/)

Leaflet is an open-source JavaScript library for creating interactive web maps. We will use it to build interactive maps, work with GeoJSON, and explore the fundamentals of web mapping.

[Learn more about Leaflet →](leaflet)

---

### [MapLibre GL JS](https://maplibre.org/)

MapLibre GL JS is an open-source JavaScript library for building interactive maps using vector data and modern web mapping technologies. We will use it to explore vector tiles, styling, and more advanced web mapping workflows.

[Learn more about MapLibre GL JS →](maplibre)

---

## What You Do *Not* Need to Install

Several technologies appear in the course because they are part of the Web GIS ecosystem, but they are **not required desktop installations** for students.

You do **not** need to install:

- HTML
- CSS
- JavaScript
- Leaflet as a desktop application
- MapLibre GL JS as a desktop application
- ArcGIS Online as a desktop application

HTML, CSS, and JavaScript are languages used to build web applications. You will work with them primarily through Visual Studio Code.

Leaflet and MapLibre GL JS are JavaScript libraries that will be incorporated into your web mapping projects.

---

## Before the Course Begins

Before starting the first lab, make sure you have:

- [ ] A modern web browser such as Chrome, Firefox, or Microsoft Edge
- [ ] Visual Studio Code installed
- [ ] The **Live Server** VS Code extension installed
- [ ] QGIS installed
- [ ] Git installed
- [ ] A GitHub account
- [ ] Access to your WNMU ArcGIS Online account

You do **not** need prior programming or web development experience. We will introduce HTML, CSS, JavaScript, and web GIS development concepts during the course.

> **Don't worry about installing everything at once.** Some tools and technologies will be introduced later in the semester, and the course materials will provide additional instructions when you need them.
